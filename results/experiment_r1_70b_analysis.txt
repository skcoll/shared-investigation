2. CRITICAL FINDING: BASELINE WITHOUT INTERVENTIONS FAILS
================================================================================

Condition A (baseline/none) is the ONLY condition that fails: 0/3 solved.

Run details:
  A_1: 20 steps, 4 tool calls, ALL file() — never progressed. Action gap 0.20
  A_2: 20 steps, 4 tool calls, ALL file() — never progressed. Action gap 0.80
  A_3:  7 steps, 2 tool calls, ALL file() — never progressed. Action gap 0.71

The 70B baseline without interventions exhibits the SAME pathology as the 14B:
it calls file() repeatedly and never advances to strings(), disasm(), or
run_binary(). Avg unique tools = 1.0 (only file).

This is the paper's strongest data point: a 70B model with demonstrated
RE capability (it solves in all other conditions) fails when it has neither
structured state nor interventions to guide its investigation.


================================================================================
3. STRUCTURED STATE VS INTERVENTIONS: WHICH MATTERS MORE?
================================================================================

The 70B results let us disentangle state visibility from interventions:

                         No Interventions    Light Interventions
  Baseline (no state)    A: 0/3 FAILS        B: 3/3 solves (8.3 steps)
  Structured (state)     C: 3/3 solves       D: 3/3 solves (12.7 steps)

Key insight: EITHER structured state OR interventions is sufficient to solve.
Neither alone is necessary — but at least one is required.

The baseline needs interventions to solve (A→B: 0/3 → 3/3).
The structured agent solves without interventions (C: 3/3).
Adding interventions to structured doesn't help (C→D: same solve rate, slower).

This is a clean 2x2 result:
  - State alone: sufficient
  - Interventions alone: sufficient
  - Neither: fails
  - Both: sufficient but no additive benefit


================================================================================
4. ACTION GAP ANALYSIS
================================================================================

Action gap (model describes action without executing):

  A: baseline/none     = 0.571 (57% of steps!)
  B: baseline/light    = 0.122 (12%)
  C: structured/none   = 0.048 (5%)
  D: structured/light  = 0.022 (2%)
  E: structured/strong = 0.042 (4%)

Structured state reduces action gap from 57% to 5% (91% reduction).
Interventions reduce baseline action gap from 57% to 12% (79% reduction).

Both mechanisms suppress the "describe but don't execute" pattern, but
structured state is more effective.

================================================================================
7. IMPLICATIONS FOR THE PAPER
================================================================================

The three-model comparison tells a scaling story:

AT SMALL SCALE (14B):
  The model can't solve regardless, but structured state changes
  HOW it fails — more diverse tools, lower action gap, more experimentation.
  This is the "behavioral effect" argument.

AT MEDIUM SCALE (70B):
  The model CAN solve, but ONLY with guidance (structured state or
  interventions). Without either, it exhibits the same file()-loop
  pathology as the 14B. This is the "necessity" argument — structured
  state is necessary for the model to deploy its full capability.

AT FRONTIER SCALE (Kimi K2):
  The model solves independently, but structured state still produces
  more thorough investigations (lower action gap, more disasm calls).
  This is the "quality" argument — structured state improves investigation
  quality even when not needed for task completion.

Together: "Structured state is a coordination substrate that enables
effective investigation behavior. At small scale it changes how the agent
fails. At medium scale it determines whether the agent succeeds. At
frontier scale it improves investigation quality."


================================================================================
8. RECOMMENDATIONS
================================================================================

1. LEAD WITH THE 70B 2x2 RESULT in the paper — it's the cleanest and
   most compelling data point.

2. ADD HARDER CHALLENGES where even the 70B structured agent struggles.
   This would reveal whether interventions provide additional benefit
   beyond state on harder tasks (currently they don't on this easy task).

3. INCREASE SAMPLE SIZE to 10 runs per condition on the 70B for
   statistical significance.

4. THE 14B AND KIMI DATA ARE SUPPORTING EVIDENCE for the scaling
   argument, not the primary result.
