I disassembled main and found that the calls to the function at 0x1348
take string arguments that appear obfuscated.  I examined the code in
that function and found where the strings are decoded before being
printed (function at 0x1218).  I stepped through this function several
times, watching how the strings are decoded a piece at a time.

The solution was a matter of decoding all of the strings, until finding
one that is the correct password.

I ran the program in radare2, setting a break point at 0x000012c4.
When execution reached the first breakpoint, I changed the value of
rdi from 0x2004 ("Gtu.}'uj{fq!p{$") to 0x2033 ("fhz4yhx|~g=5").  After
continuing execution, the program printed the password instead of
the warning not to simply patch the binary:
