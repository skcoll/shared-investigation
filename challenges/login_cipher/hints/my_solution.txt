It looks like basic string encryption:
1. number = 0x7b1
2. for each character apply some math (c = c + (number // 10) * 10 - number)
3. in each iteration we update the number: number = number*7 & 0xffff

Here is implementation of this function in python:
def convert(s):                                                                 
    const = 0x7b1                                                               
    l = list(s)                                                                 
    for i, c in enumerate(l):                                                   
        const = (const * 7) & 0xffff                                            
        l[i] = chr(ord(c) + (const / 10) * ord('\n') - const)                   
    return ''.join(l)
